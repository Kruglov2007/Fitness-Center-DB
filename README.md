# 🏋️‍♂️ Fitness Center Management System (MS Access + MySQL)

Реляционная база данных для автоматизации работы фитнес-центра. Проект реализован с разделением логики (хранение данных в **MySQL**) и интерфейса (формы, запросы и отчеты в **Microsoft Access**). Связь между системами осуществляется через **ODBC-драйвер**.

Система позволяет вести комплексный учет клиентов, проданных абонементов, расписания тренировок, инвентаря, персонала и дополнительных услуг клуба.

---

## 📊 Схема данных и Архитектура

Данные хранятся на сервере MySQL. Архитектура построена на связях «один-ко-многим» (1:M) и включает следующие сущности:

- **clients** — персональные данные клиентов и контакты.
- **memberships** & **client_memberships** — тарифная сетка клубных карт и журнал продаж абонементов.
- **staff** — учет сотрудников фитнес-центра по должностям.
- **room** — залы и их вместимость.
- **classes** & **class_registrations** — расписание тренировок, закрепленные тренеры и запись клиентов на занятия.
- **services** & **service_orders** — учет продаж дополнительных услуг (фитнес-бар, массаж, персональные тренировки).
- **check_ins** — журнал посещений (время входа/выхода) и контроль занятых шкафчиков.
- **equipment** — инвентаризационный учет тренажеров по залам с контролем их технического состояния.

---

## 📈 Реализованная отчетность в MS Access

Все отчеты спроектированы вручную в **режиме Конструктора (Design View)** с автоматическим выводом текущей даты, времени и нумерации страниц (вид `Страница N из M`).

1. **«Оборудование»** — инвентаризационная ведомость тренажеров и техники с фильтрацией по статусу готовности.
2. **«Итоги_Продаж»** — финансовый аудит продаж клубных карт с группировкой по типам абонементов и автоматическим подсчетом выручки по группам и итогового дохода клуба.
3. **«Сотрудники»** — анализ кадрового состава с группировкой по должностям (`role`) и подсчетом штата сотрудников.
4. **«Доходы_Услуги»** — аналитика выручки от продаж сопутствующих услуг на основе реляционного SQL-запроса.
5. **«Записи_на_Занятия»** — журнал контроля посещаемости групповых тренировок для администраторов и тренерского состава.

## 🚀 Инструкция по развертыванию проекта на другом компьютере

Чтобы запустить проект на новом компьютере, необходимо восстановить базу данных в MySQL и связать её с интерфейсом Access. Follow these steps:

### Шаг 1. Восстановление базы данных в MySQL
1. Убедитесь, что у вас запущен локальный сервер MySQL (через MySQL Installer, Open Server, XAMPP и т.д.).
2. Откройте **MySQL Workbench** и подключитесь к серверу.
3. В левой панели нажмите правой кнопкой мыши по пустому месту в секции **SCHEMAS** и выберите **Create Schema...** (Создать базу данных). Назовите её **`fitness_club`**.
4. Откройте вкладку **Administration** (над списком схем) -> **Data Import/Restore**.
5. Выберите пункт **Import from Self-Contained File** и укажите путь к файлу `fitness_club_backup.sql` из этого репозитория.
6. В поле **Default Target Schema** выберите созданную базу `fitness_club`.
7. Перейдите во вкладку *Import Progress* и нажмите кнопку **Start Import**.

### Шаг 2. Установка ODBC-драйвера в Windows
1. Скачайте и установите **MySQL Connector/ODBC** с [официального сайта MySQL](https://mysql.com).
2. **Важно:** Разрядность драйвера (x86 или x64) должна строго совпадать с разрядностью вашего **Microsoft Access / Office**, а не операционной системы Windows! Если у вас 32-битный Office, устанавливайте драйвер `x86`.

### Шаг 3. Настройка источника данных ODBC
1. Откройте поиск Windows, введите **«Источники данных ODBC»** (ODBC Data Sources) и запустите утилиту нужной разрядности.
2. На вкладке **Пользовательский DSN** (User DSN) нажмите кнопку **Добавить...**
3. Выберите из списка **MySQL ODBC Unicode Driver** и нажмите *Готово*.
4. Заполните параметры подключения:
   - **Data Source Name (DSN):** `MySQL_Fitness` *(название должно быть именно таким!)*
   - **TCP/IP Server:** `localhost` (или `127.0.0.1`)
   - **User:** `root` (или имя вашего пользователя MySQL)
   - **Password:** *(ваш пароль от сервера MySQL, если он есть)*
   - **Database:** выберите из выпадающего списка базу `fitness_club`.
5. Нажмите кнопку **Test**, убедитесь в появлении сообщения *«Connection Successful»* и нажмите **OK**.

### Шаг 4. Запуск проекта
Запустите файл **`Database1.accdb`**. Microsoft Access автоматически подтянет все связанные таблицы из вашей локальной базы данных MySQL. Проект готов к работе!
