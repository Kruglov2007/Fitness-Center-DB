# 🏋️‍♂️ Fitness-Center-DB — База данных фитнес-центра

Реляционная база данных для автоматизации процессов фитнес-центра, разработанная в среде **Microsoft Access**. Проект включает в себя спроектированную логическую схему данных со связями «один ко многим», а также комплексный набор пользовательских форм для удобного ввода, редактирования и просмотра информации.

## 📊 Структура базы данных (Схема данных)

База данных состоит из взаимосвязанных таблиц, которые условно разделены на справочники и операционные журналы:

### 📋 Справочники (Основные сущности):
* **`clients` (Клиенты)** — персональные данные посетителей (имя, фамилия, контакты).
* **`staff` (Сотрудники)** — информация о тренерском составе и персонале.
* **`room` (Залы / Комнаты)** — помещения фитнес-центра, где проходят занятия.
* **`services` (Дополнительные услуги)** — перечень и стоимость доступных услуг (например, массаж, солярий, персональные тренировки).
* **`memberships` (Типы абонементов)** — тарифные планы и условия клубных карт.

### 🔄 Процессы и логи (Связующие таблицы):
* **`classes` (Занятия)** — расписание тренировок (связывает залы, названия занятий и тренеров).
* **`class_registrations` (Записи на занятия)** — журнал регистраций клиентов на конкретные тренировки.
* **`check_ins` (Посещения)** — учет визитов клиентов (время входа/выхода, номер выданного шкафчика).
* **`client_memberships` (Абонементы клиентов)** — купленные клиентами клубные карты с привязкой к датам действия.
* **`service_orders` (Заказы услуг)** — фиксация покупки клиентами дополнительных услуг.
* **`equipment` (Оборудование)** — учет инвентаря и тренажеров с привязкой к конкретным залам.

## 🖥️ Реализованный интерфейс (Формы)

Для всех таблиц созданы удобные графические формы. В связанных сущностях вместо числовых идентификаторов (ID) автоматически выводятся текстовые названия и имена для повышения читаемости данных:

1. **Составная_Клиенты** — главная форма для работы с клиентами, включающая встроенную подформу с историей их абонементов.
2. **Занятия (Расписание)** — карточки занятий с отображением названия тренировки, ФИО тренера и зала.
3. **Записи на занятия** — журнал бронирования мест на тренировках.
4. **Посещения** — форма-лог для фиксации визитов на ресепшене.
5. **Заказы услуг** — интерфейс для оформления продаж дополнительных услуг.
6. **Оборудование** — учет инвентаря с указанием его статуса и расположения.
7. **Комнаты, Сервисы, Сотрудники** — формы-справочники для оперативного наполнения базы.

## 🚀 Как запустить проект

1. Склонируйте репозиторий или скачайте файл `Database1.accdb`.
2. Откройте файл с помощью **Microsoft Access** (рекомендуется версия 2016 или новее).
3. При появлении предупреждения системы безопасности нажмите кнопку **«Включить содержимое»** (Разрешить макросы/запросы), чтобы формы и связи работали корректно.
4. Перейдите на панель объектов слева, выберите раздел **«Формы»** и откройте любую нужную форму для начала работы.
